# Deep Learning Based Sentiment Analysis on IMDB Movie Reviews

## Project Overview

This project aims to classify IMDB movie reviews as positive or negative using a Deep Learning model. The model was trained on the IMDB Dataset of 50K Movie Reviews and uses an LSTM-based neural network architecture for sentiment classification.

## Technologies Used

* Python
* TensorFlow
* Keras
* Streamlit
* Pandas
* NumPy
* Scikit-Learn

## Dataset Source

* IMDB Dataset of 50K Movie Reviews (Kaggle)

## Model Architecture

* Tokenizer
* Padding
* Embedding Layer
* LSTM Layer
* Dropout Layer
* Dense Output Layer

## Results

* Test Accuracy: 87.25%
* F1 Score: 0.87

The model successfully classifies movie reviews and demonstrates the effectiveness of Deep Learning techniques in Natural Language Processing tasks.

## Streamlit Application

This Streamlit application allows users to enter a movie review and instantly receive a sentiment prediction. The trained Deep Learning model analyzes the review text and classifies it as either positive or negative.
